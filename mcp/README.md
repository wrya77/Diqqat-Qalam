# جسر دقة قلم ↔ Claude (MCP محلّيّ)

تكتب الفكرة لكلاود بالعربية، فيُنتج دقة قلم ملفّ القصّ على قرصك مباشرةً — بلا نسخٍ ولصق.

> مثال: «اصنع كلمة **مرحباً** بخطّ كوفي، ارتفاع الحرف ٣٠سم، خامة أكريليك ٥مم»
> → يظهر ملفّ `.gcode` للآلة و`.svg` للمعاينة في مجلّد `exports/`.

## كيف يعمل (باختصار)

لا متصفّح ولا خادم ولا شبكة. الخادم المحلّيّ يكرّر مسار صفحة الخطّ نفسه في Node:

```
نصّ عربيّ → HarfBuzz (تشكيل) → opentype (مخطّطات) → CalligraphyEngine → GCodeGenerator → ملفّ
```

كلّ ذلك من `shared/` و`public/vendor/` الموجودة أصلاً — فالناتج **مطابقٌ** لما يُنتجه التطبيق، وبلا أي تبعيةٍ جديدة سوى حزمة بروتوكول MCP نفسها (معزولة هنا في `mcp/node_modules`).

## الأدوات المتاحة لكلاود

| الأداة | ماذا تفعل |
|---|---|
| `list_fonts` | يعرض الخطوط الأربعة (نسخ، حديث، كوفي، رقعة) |
| `make_letters` | يصنع الحروف من نصٍّ ويكتب `.gcode` + `.svg` |

معاملات `make_letters`: `text` (إجباريّ) · `font` · `heightMM` · `material` · `lineSpacing` · `toolDiameter` · `passDepth` · `feedXY` · `feedZ` · `rpm` · `formats` · `outDir`. كلّها عدا النصّ لها قيمٌ افتراضية معقولة.

## التثبيت

```bash
cd mcp
npm install
```

تحقّقٌ سريع (يُنتج ملفّات اختبار في `exports/`):

```bash
npm run smoke
```

## الربط مع Claude Desktop

أضِف هذه الكتلة إلى ملفّ إعداد Claude Desktop:

`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "diqqat-qalam": {
      "command": "node",
      "args": ["E:\\projects\\Diqqat-Qalam\\mcp\\server.js"]
    }
  }
}
```

إن كان الملفّ يحوي مفاتيح أخرى، **ادمج** `mcpServers` فيه ولا تستبدل الملفّ كلّه.

ثمّ **أعِد تشغيل Claude Desktop** كاملاً (أغلقه من شريط المهام). بعدها تظهر الأداتان، وتكتب فكرتك فينفّذها.

## ملاحظات

- **لا يحتاج خادم الويب يعمل** — المحرّك مكتفٍ بذاته.
- الملفّات تُكتب افتراضياً في `exports/` داخل المشروع؛ غيّرها بمعامل `outDir`.
- `rpm: 0` مناسبٌ لليزر/البلازما؛ ضع دوران المغزل للراوتر/المطحنة.
- الخطوط: `amiri` نسخ · `cairo` حديث · `reem` كوفي · `ruqaa` رقعة.
